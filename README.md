# JAZZ.OS

Landing da **Jazz Automations** — a agência que roda sozinha.

Interface em pegada retro-OS: desktop verde com janelas arrastáveis, taskbar
funcional (abrir/fechar/minimizar/foco), corrida de terminais ao vivo, relógio
e boot animado. Página estática, sem build.

- Fontes livres: Archivo · JetBrains Mono · VT323 (Google Fonts)
- Sem dependências, sem framework — só `index.html`
